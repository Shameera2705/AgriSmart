# 🌾 AgriSmart - Intelligent Crop Recommendation System

## 📖 Overview
AgriSmart is a C++ Object-Oriented Programming project that recommends the most suitable crops based on environmental and soil conditions. The system analyzes farmer inputs and provides intelligent crop recommendations along with irrigation methods, fertilizers, compatibility score, and expected production.

---

## ✨ Features

- 🌱 Intelligent Crop Recommendation
- 📚 Database of 20 Crops
- 🔍 Search Crop by Name
- 📋 View All Crops
- 🌧️ Rainfall Analysis
- 🌡️ Temperature Analysis
- 🧪 Soil pH Analysis
- 💧 Humidity Analysis
- 🌿 Soil Moisture Analysis
- 🚰 Water Availability Analysis
- 🌾 Fertilizer Recommendation
- 💦 Irrigation Recommendation
- 📈 Expected Production Calculation
- 📊 Compatibility Score
